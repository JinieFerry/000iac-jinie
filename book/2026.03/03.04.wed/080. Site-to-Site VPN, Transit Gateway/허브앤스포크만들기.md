# 허브앤 스포크 만들기

## 1단계 :  Spoke 생성

1. 스포크 vpc : spoke01
+ 대표 IP : 10.10.0.0/24
+ 서브넷 : public 0개 / private 2개 : 10.10.10.0/24 10.10.20.0/24
(1) 서브넷 연합 associataion : private1과 2 : 합치지 않으면 라우팅 테이블을 각각 만들어야 함    

2. 스포크 private 안에 EC2 우분투 nginx 설치  ex) 10.10.1.1로 생성 <------ 계획했으나 실제로는 되어있지 않았음
(1) 후작업: 보안그룹에서 http , https , ssh , icmp 열기      

## 2단계 : Hub VPC 생성
1. Hub01 VPC 생성
+ 이름: hub01
+ 10.0.0.0/16
+ public 2개 : 10.0.10.0/24 , 10.0.10.0.20/24
+ private 2개 : 10.0.30.0/24 , 10.0.40.0/24
(1) public 서브넷 합치기     
(2) private 서브넷 합치기   

2. bastion 서버 생성 : SSH 서버 접속용 - hub01 vpc 프라이빗 네트워크에 구축 (해킹 방지) -> 접속 안됐음
(1) 접속 방법 : Elastic IP는 유료, EC2 > 인스턴스 > '연결' - 공인 IP 받기 하지않고, 프라이빗 연결 - endpoint 생성 연결 - aws terminal로 연결   
(2) spoke 접속 테스트 : - aws terminal     
(3) 후작업 : spoke Nginx 연결 테스트 ping (성공) , curl (안 됨), ssh (안 됨 -> awskey8.pem 파일을 직접 만들어서 넣었더니 됐음) test
