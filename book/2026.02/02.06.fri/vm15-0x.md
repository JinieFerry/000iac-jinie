+ vm15-02 → 192.168.115.2/16


1-3. machine-id 재생성

+ 실행 노드:모든 VM
+ 작업 위치: 루트(/) 기준
```
# 기존 machine-id 삭제
sudo rm -f /etc/machine-id
sudo rm -f /var/lib/dbus/machine-id

# 새로운 machine-id 생성
sudo systemd-machine-id-setup

# 확인
cat /etc/machine-id # VM마다 다른 값이면 정상
```
1-4. cloud-init 초기화

+ 실행 노드:모든 VM
+ 작업 위치:어디서 실행해도 무관
```
# instance-id 삭제
sudo cloud-init clean --logs # 이미 초기화된 VM 상태 제거

# 확인 (선택)
sudo cat /var/lib/cloud/data/instance-id
```

### SHH키 설정 + Kubernetes JOin
+ Xshell에서 패스워드 입력 없이 접속 되도록
+ k8s master에서 토큰 생성 -> worker node join
  + 모든 노드: SSH  키 설정 (비밀번호 로그인 제거)
  + 마스터 노드: kubeadm join 토큰 생성
  + 워커 노드: kubeadm join 실행 

1.SSH키 생성(비밀번호 없이 Xshell접속)
+ vmmaster1 ssh키 생성 
```
# 마스터 노드에서 
ssh-keygen -t rsa -b 4096 # 전부 enter 누르기
```

+ 다른 노드에 공개키 배포
```
# 방법 1 : 호스트네임으로
ssh-copy-id master@<워커노드의 호스트네임>
# 방법 2: IP로
ssh-copy-id master@<워커노드의 IP주소>
```
+ 이 단계에서만 비밀번호 입력(1234) : 성공 후 부터는 비밀버호 입력하지 않음

2.SSH 비밀번호 로그인 차단
+ 모드 노드에서 실행
```
#마스터,워커노드 모두에서 실행
sudo vi /etc/ssh/sshd_config

# 아래 항복 확인/수정
PasswordAuthentication no
PubkeyAuthentication yes

# 적용
sudo systemctl restart sshd
```

3. Xshell에서 접속테스트
`ssh master@vm15-0x` #접속할 vm 호스트네임
