##### vm15-01셋팅
1-1. netplan 설정 수정 (예: vm15-01)
+ vm15-01 → 192.168.115.1/16
+ vm15-02 → 192.168.115.2/16
+ vm15-03 → 192.168.115.3/16
+ vm15-04 → 192.168.115.4/16

```
# 아이피 할당
sudo vi /etc/netplan/50-cloud-init.yaml

# netplan 적용
sudo netplan apply

# 확인
ip a
ip route
```
1-2. Hostname 변경

 + 실행 노드 : 모든 VM
 + 작업 위치 : 어디서 실행해도 무관
```
sudo hostnamectl set-hostname <호스트네임> #vm15-01 (각 노드에 맞게 변경)

# 확인
hostname
```
1-3. machine-id 재생성

+ 실행 노드:모든 VM
+ 작업 위치: 루트(/) 기준
```
# 기존 machine-id 삭제
sudo rm -f /etc/machine-id
sudo rm -f /var/lib/dbus/machine-id

# 새로운 machine-id 생성
sudo systemd-machine-id-setup

# 확인
cat /etc/machine-id # VM마다 다른 값이면 정상
```
1-4. cloud-init 초기화

+ 실행 노드:모든 VM
+ 작업 위치:어디서 실행해도 무관
```
# instance-id 삭제
sudo cloud-init clean --logs # 이미 초기화된 VM 상태 제거

# 확인 (선택)
sudo cat /var/lib/cloud/data/instance-id
```
1-5. 재부팅 (필수)

+ 실행 노드: 모든 VM

`sudo reboot`

1-6. 재부팅 후 마지막 최종 확인
```
#호스트네임: vm자기PC번호-0x
hostname
#고정 IP: 192.168.1자기PC번호.x/16
ip a
#머신 ID
cat /etc/machine-id
```
