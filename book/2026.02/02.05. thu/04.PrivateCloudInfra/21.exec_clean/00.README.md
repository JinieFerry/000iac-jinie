# 21.exec_clean — Kubernetes 실습 (클린 버전)

이 파트는 Kubernetes 기본 웹 배포부터 스토리지 연동까지
실습이 꼬이지 않고, 재현 가능하며, 디버그가 쉬운 구조를 목표로 재정비한다.

---

##  실습 목표
- YAML 기반으로 Nginx 웹 서버를 배포한다
- NodePort를 통해 외부 브라우저에서 접속한다
- 리소스 상태를 직접 확인하고 검증한다

---

##  전제 조건
- Kubernetes 클러스터 정상 동작
- 모든 노드 `Ready` : 이번에는 vmmaster1,vm1만 사용
- swap off 완료
- 방화벽에서 NodePort 허용 : 사전정비.md참고 (6443)
