아래 항목 중 하나라도 정상 상태가 아니면 실습이 꼬인다. 모두 체크 한 후 다음 단계를 진행한다. (=> 10.k8s-basics/10.nginx-nodeport.yaml)

1. 노드 상태 확인 : `kubectl get nodes`
   + 모든 노드 Ready
   +  실습에서 사용하는 노드 중 하나라도 NotReady가 있으면 Ready를 먼저 시키고 실습 진행
     > control-plane: vmmaster1
     > worker: vm1
  
2. API 서버 확인 : `kubectl cluster-info`
   + 정상 응답 : https://<MASTER-IP>:6443 <- 열어둔 포트가 떠야 함
     > 정상 출력 예시:
     > `Kubernetes control plane is running at https://<MASTER-IP>:6443`
   + 또는 직적 확인: `curl -k https://<MASTER-IP>:6443/healthz`
     > 정상 응답: ok
     > 응답없음/타임아웃 시 6443포트 자체 혹은 방화벽 문제(방화벽에서 64443/tcp 열지 않은 상태)
     
    
3. swap off 확인 : `swapof --show`
   + sawp on을 출력하는 명령으로 출력이 없어야 정상 상태
   + swap on 상태에서는 kubelet 정상 동작 불가
     
4. 방화벽/포트 확인:
   + 필수포트 열려있어야 함:
     + API Server: 6443
     + NodePort: 30080 (실습용) 
   
   + VM / 클라우드 환경에서는 다음을 반드시 확인:
     >UFW / firewalld
     >보안 그룹(Security Group)
     >사설망/브리지 네트워크 정책
     
6. 이미지 PULL 테스트=네트워크 확인
```
kubectl run test --image=nginx --restart=Never
kubectl delete pod test
```
   + 정상 상태: 상태: Running → Completed 또는 Running

7. 정리 `kubectl delete pod test`
   >ImagePullBackOff, ErrImagePull 발생 시
   >노드인터넷연결
   >DNS
   >프록시 설정 확인
