2. 파일생성
+ 10.k8s-basics/nginx-nodeport.yaml
```
cd ~/10.k8s-basics
touch nginx-nodeport.yaml
vi nginx-nodeport.yaml #wq!
```
+ nginx-nodeport.yaml에 들어갈 내용
```
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  replicas: 2
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:alpine #latest에서 alpine(가벼움)으로 수정
        ports:
        - containerPort: 80
---
apiVersion: v1
kind: Service
metadata:
  name: nginx-service
spec:
  type: NodePort  # 외부 접속을 위해 NodePort 설정
  selector:
    app: nginx
  ports:
    - protocol: TCP
      port: 80        # 서비스가 사용하는 포트
      targetPort: 80  # 파드(컨테이너) 내부 포트
      nodePort: 30080 # 노드에서 열릴 포트 (30000-32767 범위 내 선택 가능)
```
