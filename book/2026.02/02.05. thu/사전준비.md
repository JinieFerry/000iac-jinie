#### 1. 샘플 체크: 트러블 예측 | 04.PrivateCloudInfra/21.exec/
1. backend = python:3.9-slim + flask 코드 인라인
→ 기본 이미지에 Flask 없음 → CrashLoopBackOff (너가 이미 잡았지)

2. Service port/targetPort 불일치가 섞여 있음

어떤 곳은 backend service가 port 80 / targetPort 5000

어떤 곳은 port 5000 / targetPort 5000

1. backend-deployment.yaml :Service가 80 → 5000
>kind: Service 아래 ports가 문제 됨
```
apiVersion: v1
kind: Service
metadata:
  name: backend-service
spec:
  selector:
    app: backend
  ports:
  - protocol: TCP
    port: 80          # <- 여기 (80)
    targetPort: 5000  # <- 여기 (5000)
```
>Service 입구를 80으로 열어놓고 Pod는 5000으로 보내는 듯

2. backend-setup.yaml:500-> 5000 (3-Tier Demo 파트)
>kind: Service 아래 ports가 문제 될 듯
```
apiVersion: v1
kind: Service
metadata:
  name: backend-service
spec:
  ports:
    - port: 5000       # <- 여기 (5000)
      targetPort: 5000 # <- 여기 (5000)
  selector:
    app: backend
```
>Service도 5000, Pod도 5000인 상태

3. frontend-setup.yaml (3-Tier Demo 파트)
>ConfigMap의 nginx 설정이 충돌 일으킬 듯
```
location /api/ {
  proxy_pass http://backend-service:5000;
}
```
>backend Service가 port 80이면 층돌 날 듯.
(nginx는 :5000으로 붙는데, Service는 5000을 안 열어줌`

4. Nginx에 PVC를 /usr/share/nginx/html 통째로 마운트
→ 기본 index.html 사라짐 + 빈 디렉토리면 403 뜰 수 있음
ConfigMap + subPath로 index.html만 덮는 게 정석일 듯

5. NFS 파트가 3개 버전으로 중복

Ansible 버전 / 수동 버전 / “VM50” 버전이 섞여서 “무슨 걸 따라야 하는지”가 깨짐
→  VM50 수동 설치 + PV/PVC YAML이 가장 단순

5. 3-Tier/MySQL/MariaDB까지 확장
 NGINX NodePort 성공 먼저 시킨 후에 25로 (프론트 nginx NodePort)랑 섞이지 않도록)
