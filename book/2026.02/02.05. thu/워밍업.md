함)

서비스: 고유한 역할 >>> 네트워크 접속 서비스     
yaml의 service 칸에서 node port를 이용하는 것 : 접속할 때 접속 방식이 내부적으로는 아이피로 통신을 하지만 각 노드로 가고 서비스를 찾아야 하므로 포트로 연결을 해줘야 함, 노드 안에서 누구한테 갈거냐는 (아이피는 주소, 포트느 문)     

내꺼: 노드포트, 클러스터 아이피(보통 내부에서만 씀) - 파드끼리 , 노드끼리 통신하는 것 = 서비스 아이피 : 노드 포트를 먼저 쓰는 게 맞음  
클라우드 회사꺼(RDB관련된 걸 클라우드 회사꺼 쓸 때): 로드발란서: 클라우드에서 서비스하는 장비   우리는 로드발란서 외부에 있는 거 쓰고 있어만 선언함 , 익스터널레인


yaml에서 쓰이는 포트: 3개   
+ port
+ target port
+ node port

```
    nodeport
port:80                 # 서비스 포트 = 서비스 IP랑 물려있음 : 서비스 라벨을 보고 찾음
    target-port:8080    # pod의 포트
    node-port:3108      # node의 포트 # 내부에서 할 때 찾는 것 (숨겨져 있음)
```
